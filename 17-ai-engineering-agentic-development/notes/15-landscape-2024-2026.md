# 15 — Landscape 2024–2026

Danh sách này ghi **xu hướng kiến trúc**, không phải bảng xếp hạng model. Model name, quota, price và preview status phải kiểm tra lại trước deploy.

## Những thay đổi đáng học

### Từ chat completion tới response/interaction

API hiện đại quản lý multimodal input, reasoning, tool calls, state/continuation và streaming events trong một response abstraction. Với OpenAI, Responses API là hướng ưu tiên cho reasoning/tool/multi-turn mới. Ứng dụng vẫn nên giữ state canonical và adapter provider để tránh lock-in.

### Structured output và tool use thành primitive

JSON schema/function declaration giúp output parse được, nhưng semantic/business validation vẫn ở application. Parallel/compositional tool calls tăng năng lực và đồng thời tăng nhu cầu budget, idempotency và policy.

### Context dài không thay retrieval engineering

Context window lớn và caching giúp xử lý corpus/prefix lớn, nhưng relevance, ACL, freshness, latency và cost vẫn cần retrieval/context selection. “Dump everything” dễ tạo lost-in-the-middle và injection surface.

### Agent trở thành runtime problem

Trọng tâm chuyển từ prompt sang harness: state, tools, permissions, approvals, retry, stop, trace và eval. Multi-agent xuất hiện trong framework/API nhưng vẫn là trade-off, không phải target architecture mặc định.

### Interoperability trưởng thành

MCP revision 2026-07-28 chuyển core sang stateless và có extension framework; A2A published spec 0.3.0 nhắm agent-to-agent tasks. Versioning/auth/conformance quan trọng hơn demo “connect được”.

### Eval và observability trở thành release gate

Teams chuyển từ demo subjective sang dataset, code/model graders, retrieval metrics, trajectory trace và cost per successful task. GenAI telemetry conventions còn đổi nên cần abstraction nội bộ/version pin.

### Agentic security là lớp riêng

Prompt injection, tool misuse, data exfiltration, poisoned memory và excessive agency được threat-model rõ hơn. NIST GenAI profile và OWASP agentic guidance bổ sung cho secure SDLC truyền thống, không thay thế nó.

### Java ecosystem bắt kịp

Spring AI 2.0 cung cấp ChatClient, Advisors, tool calling, RAG/vector stores, MCP và observability. Senior Java nên giữ domain/application boundary và coi Spring AI là adapter/runtime integration, không để provider API lan vào core.

## Cách theo dõi thay đổi

- Subscribe release notes chính thức của provider/framework/protocol.
- Có `model capability matrix` và automated smoke/eval cho model candidate.
- Pin protocol/SDK/schema; đọc deprecation và migration guide.
- Review theo quý: model, price, latency, data terms, security advisory và eval baseline.
- Không copy model ID từ blog cũ vào production config.
