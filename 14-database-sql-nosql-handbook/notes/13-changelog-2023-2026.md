# 13 — MySQL, PostgreSQL, MongoDB: changelog 2023-2026

Phạm vi: **01/07/2023 đến 24/08/2026**. Đây là learning-oriented change list, không chép mọi patch bug/CVE. Trước upgrade phải đọc release note của **từng minor/patch** giữa bản nguồn và đích.

## Snapshot ngày 24/08/2026

| Product | Production baseline hiện tại | Ghi chú |
|---|---|---|
| MySQL | 9.7 LTS; 8.4 LTS còn phù hợp | 26.7 là Innovation; calendar versioning bắt đầu sau 9.7 |

Version mới nhất không thay thế compatibility matrix của managed provider, driver và ecosystem.

### Key changes đáng học

**8.4 LTS:**

- automatic histogram updates giúp optimizer statistics được duy trì chủ động hơn;
- Group Replication/certification garbage collection được cải tiến;
- privilege mới như `FLUSH_PRIVILEGES`, `OPTIMIZE_LOCAL_TABLE` tách quyền tốt hơn;
- thay đổi default như adaptive hash index mặc định off và change buffering mặc định `none` cần benchmark, không copy config 8.0;
- bỏ nhiều option/variable/utility/replication terminology cũ; `default_authentication_plugin` bị bỏ và chuyển sang authentication policy;
- upgrade phải kiểm tra plugin auth, removed variables, reserved words, collation, replication và query plans.

**9.x và 9.7 LTS:**

- innovation line có thể thêm behavior và loại feature deprecated nhanh hơn LTS;
- product line có thêm capability như `VECTOR` và JavaScript stored programs ở các bản 9.x; kiểm tra exact version/edition/support trước khi thiết kế phụ thuộc;
- 9.7 là LTS kế tiếp và là cầu upgrade được hỗ trợ từ 8.4; không bỏ qua supported LTS hop;
- MySQL Shell Upgrade Checker nên nằm trong pipeline rehearsal, nhưng không thay test application/plan.

**26.7:**

- chuyển version sang calendar `YY.M`; 26.7 là Innovation release tháng 07/2026;
- Innovation được support tới Innovation kế tiếp, phù hợp early adoption/evaluation hơn fleet yêu cầu vòng đời dài;
- không hiểu số `26` là major compatibility leap theo semantic versioning.

### Upgrade posture

Chọn 8.4/9.7 LTS khi cần feature stability. Chỉ đi Innovation nếu có nhu cầu feature rõ và khả năng quarterly validation. Rehearse đúng supported path; inventory connectors, Shell, Router, backup, CDC/binlog consumers và managed-service restrictions.

## PostgreSQL

### PostgreSQL 16 — 14/09/2023

- parallel execution cho `FULL`/right outer hash joins;
- logical replication từ standby, giảm tải publisher primary trong một số topology;
- parallel apply cho transaction lớn ở subscriber;
- `pg_stat_io` cho quan sát I/O theo backend/object/context;
- thêm SQL/JSON constructors/identity functions;
- cải tiến freeze/VACUUM và authentication matching regex trong `pg_hba.conf`.

**Impact:** observability tốt hơn, logical replication linh hoạt hơn; cần kiểm tra slot/WAL retention và monitoring mới.

### PostgreSQL 17 — 26/09/2024

- VACUUM có internal memory system mới, giảm memory và cải thiện maintenance;
- SQL/JSON hoàn thiện thêm, nổi bật `JSON_TABLE`;
- I/O/read và high-concurrency write được cải thiện;
- logical replication hỗ trợ failover control tốt hơn, có `pg_createsubscriber`, giữ logical slot/subscription qua `pg_upgrade` trong workflow hỗ trợ;
- incremental `pg_basebackup`, direct TLS negotiation;
- `COPY ... ON_ERROR ignore` hữu ích cho ingestion có dữ liệu lỗi được kiểm soát.

**Impact:** upgrade/HA/backup workflow có thêm lựa chọn; không bật ignore lỗi import nếu không có reject count/audit.

### PostgreSQL 18 — 25/09/2025

- asynchronous I/O subsystem tăng khả năng overlap I/O; kết quả tùy workload/storage;
- `pg_upgrade` có thể giữ optimizer statistics, giảm thời gian plan bất ổn sau upgrade;
- B-tree skip scan mở thêm plan khi query thiếu equality trên leading columns trong trường hợp phù hợp;
- native `uuidv7()` cho time-ordered UUID;
- virtual generated columns trở thành default;
- OAuth authentication support;
- `OLD`/`NEW` trong `RETURNING` cho `INSERT/UPDATE/DELETE/MERGE`.

**Impact:** test plan regression vì optimizer/path mới; kiểm tra extension/driver/auth proxy với OAuth; chọn UUID strategy có chủ đích, không migrate PK chỉ vì có function mới.

### 2026 maintenance và PostgreSQL 19

- 13/08/2026: current supported patches gồm 18.6, 17.11, 16.15, 15.19, 14.24.
- PostgreSQL 19 Beta 3 chỉ dành cho test extension/application compatibility và feedback; không phải stable production.

### Upgrade posture

PostgreSQL major upgrade không phải in-place minor patch: dùng `pg_upgrade`, logical replication hoặc dump/restore. Test extensions, collation, auth, planner, generated columns và replication. Minor releases chứa accumulated fixes; theo patch policy và release notes thay vì ở mãi `.0`.

## MongoDB

### MongoDB 7.0 — 2023

- Queryable Encryption equality queries đạt general availability;
- compound wildcard indexes;
- `$changeStreamSplitLargeEvent` cho event change stream lớn;
- gỡ nhiều hạn chế delete trên time-series collections và tích hợp cải tiến rapid releases 6.1–6.3.

**Impact:** encryption/query capability tăng nhưng key management/KMS/driver compatibility là một hệ thống riêng; wildcard index vẫn cần đo write/storage.

### MongoDB 8.0 — 02/10/2024

- cải tiến performance read/write; con số vendor công bố như “up to 36% read throughput” phụ thuộc workload, phải benchmark của mình;
- `bulkWrite` cross-collection và time-series block processing;
- allocator/caching improvements, profiler có `workingMillis`;
- query settings/query shape thay thế dần index filters;
- resharding và redistribution cùng shard key được cải thiện;
- majority write acknowledgement semantics thay đổi: acknowledgement có thể dựa trên written-to-majority trước khi apply trên secondaries, ảnh hưởng assumption causal read timing;
- `defaultMaxTimeMS`, background compaction và khả năng config shard mới.

**Impact:** review write/read concern và causal consistency; đừng tái dùng benchmark marketing làm capacity promise. Upgrade lên 8.0 yêu cầu FCV 7.0 theo official path.

### MongoDB 8.2 — 16/09/2025

- Search/Vector Search cho self-managed ở public preview;
- Queryable Encryption prefix/suffix/substring ở public preview;
- `$scoreFusion` hỗ trợ hybrid search composition;
- ingress connection establishment rate limiting;
- cải tiến `$lookup` trên encrypted collections.

**Cảnh báo:** preview không production-ready theo cùng contract với GA. 8.2.0 từng có change-stream performance regression được sửa ở 8.2.1; đây là ví dụ vì sao phải chọn latest tested patch, không dừng ở `.0`.

### MongoDB 8.3 — 04/05/2026

- Cost-Based Ranker làm backup mặc định cho eligible queries;
- overload-aware server selection và pre-authentication connection limits;
- query memory metrics và expression mới cho EJSON/hash/ObjectId;
- shard draining commands chi tiết hơn thay workflow `removeShard` deprecated;
- nhiều cải tiến query performance, security và overload protection.

Tại 11/08/2026, 8.3.8 là patch đã phát hành trong official release notes; không coi entry “upcoming” là released. Planner mới có thể đổi plan, nên capture representative queries và canary.

### Upgrade posture

- Tuân thủ từng supported major/minor hop và Feature Compatibility Version.
- Binary upgrade trước, quan sát rồi mới nâng FCV nếu cần rollback window.
- Community Edition có giới hạn downgrade; kiểm tra exact edition/path.
- Test driver, auth, encryption, change streams/resume token, shard/replica topology và backup restore.
- Đọc security fixes của mọi patch giữa source/target.

## Cross-product takeaways

1. Release train đã thay đổi: MySQL có LTS/Innovation và calendar version; MongoDB có stable/minor cadence; PostgreSQL vẫn annual major + quarterly-ish maintenance.
2. Optimizer ngày càng thay đổi nhanh (histogram, skip scan, cost-based ranker): plan regression testing là upgrade requirement.
3. Connection/overload control trở thành first-class feature, nhưng application vẫn cần pool/rate limit/retry budget.
4. JSON/vector/search xuất hiện gần relational/document core; feature tồn tại không có nghĩa thay dedicated engine hoặc phù hợp mọi workload.
5. Security/compatibility patch quan trọng hơn chạy theo headline feature; luôn pin tested patch/digest trong production.
